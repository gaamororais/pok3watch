## 2. Propósito único (single purpose)

Campo do formulário — texto sugerido:

> Monitorar passivamente a tela do jogo Poke Idle World e notificar o usuário (no WhatsApp e por notificação do sistema) sobre eventos do próprio jogo: capturas relevantes, itens raros, estoque de Pokébolas e queda de conexão. Todos os recursos existem para esse fim: as regras definem o que merece aviso, o resumo periódico agrupa os avisos, e os filtros visuais apenas escondem elementos do jogo que geram alerta falso de shiny. A extensão não automatiza nenhuma ação do jogo.

## 3. Justificativa de cada permissão

Cole cada uma no campo correspondente do formulário.

| Permissão | Justificativa |
|---|---|
| `storage` | Guardar as configurações do usuário (número de WhatsApp, API Key, regras de alerta, idioma) e o histórico local de capturas usado para montar o resumo periódico. |
| `notifications` | Mostrar o alerta também como notificação do sistema, para quem está no computador e não quer depender do celular. |
| `alarms` | Verificar a cada minuto se a aba do jogo continua respondendo. Sem isso, o monitoramento poderia parar sem o usuário perceber. |
| `tabs` | Saber se a aba do jogo continua aberta e respondendo, identificar qual aba é de qual conta e levar o usuário até ela ao clicar no status do popup. Não é usado para ler histórico nem conteúdo de outras abas. |
| `power` | Impedir que o computador entre em suspensão enquanto o monitoramento está ativo, já que a extensão foi feita para rodar durante o farm idle. |
| `sidePanel` | Permitir abrir o painel de configuração na barra lateral do Chrome, além do popup, porque a tela de regras é grande. |
| host `https://poke.idleworld.online/*` | É o jogo monitorado. A extensão lê o texto que já está na tela (log de capturas, estoque de bolas, painel de análise). |
| host `https://api.callmebot.com/*` | Serviço escolhido pelo usuário para entregar a mensagem no WhatsApp dele. |

O que marcar:

- Informações de integridade, financeiras, de autenticação, comunicações pessoais, localização, histórico de navegação, atividade do usuário, conteúdo do site → NÃO.

Declarações obrigatórias (marcar as três):
- Não vendo nem transfiro dados do usuário para terceiros fora dos usos aprovados.
- Não uso nem transfiro dados do usuário para fins não relacionados ao propósito único da extensão.
- Não uso nem transfiro dados do usuário para verificar solvência ou conceder empréstimo.

Observação para o campo de uso de dados, se houver:

Quando um alerta dispara, o texto do alerta e o número são enviados para api.callmebot.com, serviço de terceiros escolhido pelo usuário, que entrega a mensagem no WhatsApp. Não existe servidor do desenvolvedor recebendo dados.

## 7. Antes de enviar

1. Rode `node gerar-publico.js` para garantir que a pasta pública está igual à versão de desenvolvimento.
2. Rode `node empacotar.js` para gerar o .zip apenas com os arquivos que a loja precisa (o script de geração e este documento ficam de fora).
3. Confira a versão no `manifest.json`: a loja recusa reenvio com a mesma versão.
4. Instale o .zip descompactado em outro perfil do Chrome e faça um teste do zero: instalar, ver o tutorial abrir, configurar CallMeBot, receber o teste.

## 8. Riscos conhecidos da revisão

- **Nome e marca:** o nome cita o jogo e usa "Poke". Pode gerar pedido de alteração por marca registrada. Alternativa de nome, se for pedido: "Idle Catch Alerts".
- **Propósito único:** os filtros visuais (bloquear anúncios/promoções do jogo) e o lembrete de gift podem ser vistos como recursos fora do propósito. O texto da seção 2 explica a ligação; se a revisão insistir, é possível remover esses dois recursos da versão pública.
- **Permissão `power`:** é incomum e costuma gerar pergunta. A justificativa da seção 3 responde.
