# Pok3Watch

Monitor passivo para o jogo **Poke Idle World** que envia alertas no WhatsApp quando algo importante acontece: shiny, drop raro, pokébolas acabando ou o jogo desconectando.

- 🌐 **Site do jogo:** [poke.idleworld.online](https://poke.idleworld.online)
- 🔒 **Política de privacidade:** [privacy-policy.html](https://gaamororais.github.io/pok3watch/privacy-policy.html)
- ☕ **Ajude o criador:** [buymeacoffee.com/gaamorais](https://www.buymeacoffee.com/gaamorais)
- 📧 **Contato:** gaamorais1@gmail.com

## O que a extensão faz

Fica de olho na tela do jogo (**passivamente**, sem clicar em nada) e avisa por WhatsApp quando:

- Cai um **shiny** ou um Pokémon dentro das regras que você configurou (raridade, IV mínimo).
- As **pokébolas** estão acabando (estoque baixo ou zerado).
- Cai um **item raro** no Hunt Analyzer.
- O **jogo desconecta**, entra em manutenção ou a aba trava.
- O **daily gift** está disponível para resgate.

Também tem HUD sobreposto ao jogo, resumo periódico e roda em português, inglês e espanhol.

## Como funciona o envio

O alerta vai direto do seu navegador para o seu WhatsApp, via [CallMeBot](https://www.callmebot.com/) (serviço gratuito de terceiros). Não existe servidor próprio recebendo nada.

## Instalação

1. Baixe este repositório como `.zip` (**Code → Download ZIP**) ou clone.
2. No Chrome/Edge: `chrome://extensions` → ativa **Modo desenvolvedor** → **Carregar sem compactação** → aponte para esta pasta.
3. Abra o popup e siga o tutorial do CallMeBot.

## Ativar GitHub Pages (só para a política de privacidade)

**Settings** → **Pages** → **Source: Deploy from a branch** → **Branch: main / (root)** → **Save**.

Depois de alguns minutos a política fica acessível em:
`https://gaamororais.github.io/pok3watch/privacy-policy.html`
