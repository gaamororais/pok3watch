Pok3Watch — Política de Privacidade

Última atualização: 19 de setembro de 2026

Português

Pok3Watch é uma extensão de navegador gratuita, sem anúncios, que observa a tela do jogo Poke Idle World e envia alertas para o WhatsApp do próprio usuário. Esta política descreve, de forma direta, o que a extensão faz com dados.

1. O que a extensão coleta

A extensão guarda no seu próprio navegador, através de chrome.storage.local, os seguintes dados que você mesmo digita no popup:

  • Número de telefone do WhatsApp — para endereçar o alerta a você.
  • API Key do CallMeBot — chave gratuita gerada pelo próprio CallMeBot, usada para autorizar o envio da mensagem.
  • Preferências e regras de alerta (raridade, IV mínimo, idioma, itens monitorados, etc.).
  • Histórico local de capturas — usado apenas para montar o resumo periódico. Nunca sai do seu navegador.
O chrome.storage.local não é criptografado. Qualquer pessoa com acesso ao seu perfil do Chrome pode ver esses dados. Guarde esse computador como você guarda o próprio WhatsApp.

2. O que a extensão envia para fora do seu computador

Quando um alerta configurado por você dispara, a extensão envia apenas:

  • o texto do alerta (nome do Pokémon, raridade, IV, etc.), e
  • o seu número de WhatsApp e sua API Key,

para api.callmebot.com. O CallMeBot é um serviço gratuito de terceiros, escolhido por você, responsável por entregar a mensagem no seu WhatsApp. Consulte a política de privacidade deles em callmebot.com.

Não existe servidor próprio do Pok3Watch recebendo informação. Nenhum outro dado é transmitido.

3. O que a extensão NÃO faz

  • Não coleta e não envia dados de navegação, histórico ou informações pessoais além dos citados.
  • Não usa cookies, pixels de rastreamento ou identificadores publicitários.
  • Não vende, aluga ou compartilha seus dados com terceiros além do CallMeBot (necessário para o envio).
  • Não usa seus dados para publicidade, análise de crédito ou qualquer finalidade fora do propósito de mandar seus alertas.
  • Não clica, não joga e não envia comandos para o jogo — só lê o que já está na tela.

4. Como apagar seus dados

Basta desinstalar a extensão. Todo o conteúdo do chrome.storage.local é removido pelo próprio Chrome. Se quiser apagar sem desinstalar, use "Limpar dados" no popup ou chrome://extensions → Pok3Watch → Detalhes → Dados do site.

5. Contato

Para qualquer dúvida sobre privacidade, escreva para gaamorais1@gmail.com.

English

Pok3Watch is a free, ad-free browser extension that watches the Poke Idle World screen and sends WhatsApp alerts to the user themselves. This policy describes, plainly, what the extension does with data.

1. What the extension collects

The extension stores in your own browser, via chrome.storage.local, the following data that you type yourself into the popup:

  • WhatsApp phone number — to address the alert to you.
  • CallMeBot API Key — a free key issued by CallMeBot itself, used to authorize sending.
  • Alert preferences and rules (rarity, minimum IV, language, watched items, etc.).
  • Local catch history — used only to build the periodic summary. It never leaves your browser.
chrome.storage.local is not encrypted. Anyone with access to your Chrome profile can read it. Treat this computer the way you treat your own WhatsApp.

2. What the extension sends off your computer

When an alert you configured fires, the extension sends only:

  • the alert text (Pokémon name, rarity, IV, etc.), and
  • your WhatsApp number and your API Key,

to api.callmebot.com. CallMeBot is a free third-party service, chosen by you, responsible for delivering the message to your WhatsApp. See their policy at callmebot.com.

There is no Pok3Watch server receiving information. No other data is transmitted.

3. What the extension does NOT do

  • Does not collect or send browsing data, history, or personal information beyond the above.
  • Does not use cookies, tracking pixels or advertising IDs.
  • Does not sell, rent, or share your data with anyone other than CallMeBot (required for delivery).
  • Does not use your data for ads, credit scoring, or any purpose beyond sending your alerts.
  • Does not click, play, or send commands to the game — it only reads what is already on screen.

4. How to delete your data

Simply uninstall the extension. Chrome itself removes all chrome.storage.local data. To clear it without uninstalling, use "Clear data" in the popup or go to chrome://extensions → Pok3Watch → Details → Site data.

5. Contact

For privacy questions, write to gaamorais1@gmail.com.
