Pok3Watch

Para receber os alertas no celular, você precisa liberar o CallMeBot uma única vez. Leva 2 minutos.

Liberar o WhatsApp

1
Abra a página do CallMeBot: callmebot.com/blog/free-api-whatsapp-messages.
Lá aparece o número de WhatsApp do bot. Salve esse número nos seus contatos.
2
Mande esta mensagem para o contato que você acabou de salvar:
I allow callmebot to send me messages
3
O bot responde na hora com um link de teste, parecido com este:
…&text=This+is+a+test&apikey=1234567
A sua API Key é só esse final (no exemplo, 1234567) — não precisa do link todo. Se colar o link inteiro no campo da extensão, ela aproveita a chave sozinha.
Guarde essa chave só para você: quem tiver ela consegue mandar mensagem no seu WhatsApp pelo bot.
4
Clique no ícone do Pok3Watch no navegador e preencha, no topo: seu número com DDD e a API Key. As configurações salvam sozinhas. Depois clique em Testar notificação: a mensagem deve chegar no seu WhatsApp em alguns segundos.

Deixe estas janelas abertas no jogo

O Pok3Watch só lê o que está na tela. Cada janela do jogo alimenta uma parte dos alertas:
  • Log de Capturas — alertas de shiny, raridade e IV, e a lista de melhores do resumo.
  • Hunt Analyzer — saldo, loot e drops de itens raros.
  • Auto-Helper ou a barra de captura — contagem de Pokébolas.

Se não chegar mensagem

O que aparece no popupO que fazer
API Key inválida Refaça os passos 1 a 3 e cole a chave nova. A chave é só de números, sem espaços.
O CallMeBot não reconheceu este número Você precisa mandar a frase de liberação do próprio celular que vai receber os alertas. Confira também o DDD.
Limite de envios O CallMeBot é gratuito e recusa mensagens em rajada. O Pok3Watch já espaça os envios e tenta de novo sozinho.
Falha de rede Sem internet ou o CallMeBot fora do ar. O alerta aparece mesmo assim como notificação do computador.

O que a extensão faz e o que não faz

Ela só observa a tela do jogo e avisa você. Não clica, não captura, não joga e não manda nenhum comando para o jogo.

O que sai do seu computador é apenas o texto do alerta e o seu número, e vai direto para o CallMeBot, que é um serviço gratuito de terceiros e entrega a mensagem no seu WhatsApp. Número e API Key ficam salvos só no seu navegador.
